    mon["Внешний мониторинг<br/>доступности"]

    owner -- "HTTPS, браузер / телефон" --> erp
    staff -- "HTTPS, браузер / планшет, сканер-клавиатура" --> erp

    erp -- "зашифрованные копии (age + rclone)" --> storage
    mon -- "HTTPS-проверка каждые 5 мин" --> erp
    staff -. "та же продажа вводится вручную,<br/>интеграции нет (D-010)" .-> kkm

Пунктиром показаны связи, которые в MVP существуют только в реальном мире, без интеграции.
