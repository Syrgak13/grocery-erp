# Критерии приёмки

**Фаза 2 · Grocery ERP** · 26.11.2026 · статус: черновик на утверждение

> **Изменение от 27.11.2026 (Фаза 3):** продукт делается **только на русском языке** — решение D-026 в `DECISIONS.md`. Упоминания кыргызского языка (`ky`, `name_ky`, переключение языка, вычитка переводов) в этом документе отменены или переформулированы по таблице D-026. Текст ниже не переписан, чтобы сохранить утверждаемую версию Фазы 2.


Каждый критерий записан в форме «Дано / Когда / Тогда» и содержит проверяемый результат: конкретные числа, коды ошибок или пороги времени. Каждый критерий станет тестом с идентификатором `T-<ID критерия>` (`REQUIREMENTS_TRACEABILITY.md`).

Соглашения для всех критериев:
- «Сегодня» — 26.11.2026 по Asia/Bishkek, если не сказано иное.
- В примерах риска и пополнения магазин блокирует продажу в день срока (`block_on_expiry_day = да`), поэтому `sell_days = days_left` (BR-160).
- Коды ошибок — английские идентификаторы; текст сообщений берётся из ресурсов перевода ru/ky (LOC-006).
- Время ответа измеряется на сервере пилота (NFR-061) с данными по NFR-060, если не указано иное.
- Уровень теста: **U** — Юнит; **I** — Интеграционный (API); **E** — E2E (UI); **P** — Производительность; **X** — Ручной / юзабилити.
