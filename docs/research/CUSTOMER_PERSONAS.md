# Персоны, Jobs-to-be-Done и карта пути клиента

**Фаза 1 · Grocery ERP** · 26.11.2026

> **Все персоны — гипотетические [Д].** Они составлены на основе кабинетного исследования (`MARKET_RESEARCH.md`) и отраслевой логики, а **не** на основе интервью. Имена вымышлены. После 5–10 интервью персоны нужно пересмотреть, а неподтверждённые черты удалить.

---

## 1. Целевой сегмент

Независимый продуктовый магазин «у дома» в Бишкеке: 1–3 точки, 1–6 сотрудников, 500–3 000 SKU, значительная доля скоропортящихся товаров, уже применяет или обязан применять ККМ [Д]. Обоснование — `MARKET_RESEARCH.md`, раздел 11.

Покупатель решения — **владелец**. Ежедневные пользователи — **управляющий** и **кассир**.

---

## 2. Персона 1: Владелец — «Айбек, 42 года»

| | |
|---|---|
| Роль | Владелец 1–2 магазинов у дома; лицо, принимающее решение о покупке |
| Контекст | Бывает в магазине не каждый день; закупки частично делает сам, частично через торговых представителей |
| Инструменты [Д] | Банковская или облачная касса, тетрадь долгов, WhatsApp с поставщиками, иногда Excel |
| Язык [Д] | Русский и кыргызский; документы читает на русском |
| Цели | Знать реальную прибыль; сократить списания; контролировать персонал удалённо |
| Боли [Д] | Не понимает, куда «уходят» деньги; находит просрочку уже после потерь; не доверяет остаткам |
| Возражения [Д] | «Дорого», «некогда вносить товары», «касса уже есть», «боюсь налоговой прозрачности» |
| Критерий покупки [Д] | Видит сэкономленные деньги в первый месяц; цена ≤1 000 сом |

## 3. Персона 2: Управляющий — «Гульнара, 35 лет»

| | |
|---|---|
| Роль | Управляющая/старший продавец; ведёт приёмку, заказы, инвентаризацию |
| Цели | Быстро принимать товар; вовремя заказывать; не отвечать за недостачи |
| Боли [Д] | Ручная сверка накладных; сложно помнить сроки по каждой поставке; конфликт с владельцем из-за недостач |
| Что ценит [Д] | Список «что сделать сегодня»: что уценить, что вернуть, что заказать |

## 4. Персона 3: Кассир — «Нурлан, 23 года»

| | |
|---|---|
| Роль | Кассир, работает посменно |
| Цели | Быстро обслуживать очередь; не ошибаться в сдаче; закрывать смену без недостачи |
| Боли [Д] | Сложный интерфейс; товары без штрихкода; сбои связи |
| Язык [Д] | Может предпочитать кыргызский интерфейс |
| Что ценит [Д] | Минимум кликов; поиск по названию на двух языках; понятный отчёт о смене |

## 5. Jobs-to-be-Done

Формат: *Когда [ситуация], я хочу [мотив], чтобы [результат].* Все работы — гипотезы [Д].

| # | Кто | Работа |
|---|---|---|
| J1 | Владелец | Когда я подвожу итоги месяца, я хочу видеть реальную валовую прибыль, чтобы понимать, зарабатывает ли магазин. |
| J2 | Владелец | Когда меня нет в магазине, я хочу видеть продажи и остатки с телефона, чтобы контролировать персонал. |
| J3 | Владелец / управляющий | Когда у товара подходит срок годности, я хочу заранее знать, сколько денег под угрозой, чтобы успеть уценить, вернуть или переместить товар. |
| J4 | Управляющий | Когда я принимаю поставку, я хочу быстро записать количество, цену и срок годности партии, чтобы потом не искать это на полках. |
| J5 | Управляющий / владелец | Когда я готовлю заказ поставщику, я хочу получить подсказку «сколько заказать и почему», чтобы не допустить дефицита и затоваривания. |
| J6 | Кассир | Когда в очереди много людей, я хочу быстро пробить товар, чтобы не задерживать покупателей. |
| J7 | Кассир | Когда я продаю товар, я хочу, чтобы система сама списывала партию с ближайшим сроком (FEFO), чтобы остатки по срокам были верными. |
| J8 | Владелец | Когда поставщик даёт товар с отсрочкой, я хочу видеть долги поставщикам, чтобы платить вовремя. |

## 6. Карта пути клиента (владелец)

| Этап | Действия | Мысли / эмоции [Д] | Точки контакта | Возможности для продукта |
|---|---|---|---|---|
| 1. Осознание проблемы | Находит просрочку, недостачу, не сходится касса | «Опять потеряли деньги» | Полка, касса, тетрадь | Контент о потерях от просрочки; калькулятор потерь |
| 2. Поиск решения | Спрашивает знакомых, поставщиков, банк | «Все предлагают кассы, а мне нужен учёт» | Знакомые, торговые представители, банк, Instagram/WhatsApp | Партнёрство с поставщиками и банками |
| 3. Оценка | Сравнивает цену, пробует | «Дорого и сложно?» | Демо, пробный период | Пробный период, помощь с первичным вводом |
| 4. Покупка | Оплачивает подписку | «Окупится ли?» | Оплата через банк/QR | Понятный тариф в сомах |
| 5. Внедрение | Ввод номенклатуры, остатков, сроков | Самый трудный этап: «некогда» | Поддержка, импорт Excel | Импорт, шаблоны, ввод партий при приёмке, помощь онбординга |
| 6. Ежедневное использование | Продажи, приёмка, центр действий по срокам | «Удобно ли кассиру?» | Касса, телефон | Простота, двуязычие, устойчивость к сбоям связи |
| 7. Оценка ценности | Смотрит отчёт о предотвращённых потерях и прибыли | «Вижу экономию» / «не вижу смысла» | Ежемесячный отчёт | Отчёт «сэкономлено за месяц» |
| 8. Продление / рекомендация | Продлевает, советует знакомым | — | Сарафанное радио | Реферальная скидка |

**Критический этап [Д]:** этап 5 (внедрение). Если первичный ввод партий займёт больше 1–2 дней, владелец откажется. Анкета проверяет это вопросами E1–E3.
