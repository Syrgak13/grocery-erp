**Ключевое наблюдение.** Партионный учёт сроков и FEFO **существуют** у крупных систем (Odoo — нативно, МойСклад — сроки нативно, FEFO через дополнение, ERPNext — сроки партий). Значит, сама функция не уникальна. Не найдено в изученных источниках:
- сочетание «партии + FEFO + центр действий по срокам + оценка денежных потерь» в **простом продукте для магазина у дома** по цене до 1 500 сом;
- **объяснимые** рекомендации пополнения (с показом расчёта);
- кыргызская локализация.

Эти пробелы — гипотезы, которые надо проверить демо-доступом.

## 6. Позиционирование Grocery ERP

**Не конкурировать** с банковскими кассами в фискализации. **Не конкурировать** с Odoo/ERPNext по ширине функций.

**Позиция [Д]:** «Простой контроль потерь и прибыли для магазина у дома»: партии и сроки годности по умолчанию, FEFO при продаже, центр действий по истекающим товарам с оценкой денег под риском, объяснимые подсказки закупки, прозрачная валовая прибыль, русский и кыргызский, 500–1 500 сом/мес.

## 7. Что проверить до Фазы 2

1. Демо UMAG: есть ли сроки годности, партии, FEFO, цена.
2. Демо 1С:Розница: стандартный функционал по срокам годности (источник 1С не загрузился).
3. МойСклад: доступен ли учёт сроков на тарифе «Базовый» (страница указывает его в разделе «Опт»).
4. Poster: тариф с офлайн-режимом и наличие сроков в розничной версии.
5. MKassa / Bakai Kassa / O!Касса: функции товароучёта.
6. Наличие кыргызского интерфейса у всех систем.
7. Цены Odoo и R-Keeper.
