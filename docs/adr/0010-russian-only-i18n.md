# ADR-0010. Только русский язык, i18next сохраняется

**Статус:** предложено (Фаза 3, 27.11.2026) · **Журнал решений:** D-026

## Контекст

Автор решил делать продукт только на русском языке и отказаться от кыргызской локализации (27.11.2026).

## Решение

Одна локаль `ru`. Поля `name_ky`, язык пользователя и магазина, переключатель языка удаляются. i18next сохраняется: все строки в `locales/ru/*.json`, ошибки по кодам, объяснения по шаблонам, множественное число через `Intl.PluralRules('ru')`. ICU MessageFormat не нужен.

## Рассмотренные альтернативы

- **Удалить i18next и писать строки в коде** — экономит ~15 КБ, но ошибки сервера всё равно нужно переводить по коду, а добавление языка в будущем потребует переписать интерфейс; отклонено.

## Последствия

Сокращается объём работ (переводы, вычитка D-014, тесты полноты ky). Затронутые требования перечислены в D-026.
