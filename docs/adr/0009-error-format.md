# ADR-0009. Формат ошибок: RFC 9457 с кодами

**Статус:** предложено (Фаза 3, 27.11.2026) · **Журнал решений:** D-041

## Контекст

LOC-006 требует ошибки в виде кода и параметров, переводимых клиентом. Spring поддерживает Problem Details (RFC 9457).

## Решение

`application/problem+json` с полями `type`, `title`, `status` и расширениями `code`, `message` (русский), `params`, `errors[]`, `requestId`. Стабильные коды — контракт API. 409 — конфликт с текущим состоянием, 422 — нарушение бизнес-правила, 404 — и для чужих объектов.

## Рассмотренные альтернативы

- **Собственный формат `{code, message}`** — без стандарта; отклонено.
- **Только 400 для всех бизнес-ошибок** — клиенту сложнее решать, повторять ли запрос.

## Последствия

Клиент переводит по `errors.<code>`; прямые клиенты получают готовый `message`.
