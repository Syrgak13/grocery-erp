# ADR-0012. Развёртывание: Docker Compose на одном VPS, ручной deploy

**Статус:** предложено (Фаза 3, 27.11.2026) · **Журнал решений:** D-040

## Контекст

CON-009 (≤ 20 USD/мес), NFR-061 (10 магазинов на 2 vCPU / 4 ГБ), NFR-070–NFR-072 (копии, RPO 24 ч, RTO 4 ч).

## Решение

Nginx, backend, PostgreSQL 16, контейнер копий в Docker Compose на одном VPS. CI в GitHub Actions на каждый push; развёртывание — только ручной `workflow_dispatch` с внеплановой копией перед обновлением. Ежедневный `pg_dump`, шифрование age, выгрузка во внешнее S3-совместимое хранилище, 30 дней. Непрерывный архив WAL (RPO ≤ 1 ч) — по необходимости.

## Рассмотренные альтернативы

- **Управляемый PostgreSQL / PaaS** — удобнее, но дороже бюджета пилота.
- **Автоматический deploy на каждый merge** — для пилота с реальными продажами рискованно без ручного контроля.

## Последствия

Единая точка отказа — сервер; риск принят для пилота, RTO 4 ч обеспечивается документированным восстановлением.
