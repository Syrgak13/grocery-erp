# ADR-0002. Версии backend: Java 21, Spring Boot 4.2, PostgreSQL 16

**Статус:** предложено (Фаза 3, 27.11.2026) · **Журнал решений:** D-027, D-028

## Контекст

Автор предложил Java 21, Spring Boot 4.x, PostgreSQL 16 и попросил проверить совместимость по официальной документации и брать стабильные поддерживаемые версии. Проверено 27.11.2026: Spring Boot 4.2.0 вышел 19.11.2026 (поддержка OSS до 31.12.2027), 4.1.3 — поддержка до 31.07.2027, 4.0 — до 31.12.2026. Boot 4.1/4.2 поддерживают Java 17–27.

## Решение

- **Spring Boot 4.2.x**: в Фазе 4 взять последний патч ветки 4.2 (ожидается ≥ 4.2.1). Управляемые версии 4.2.0: Spring Framework 7.1.0, Spring Security 7.2.0, Hibernate 7.4.15.Final, Flyway 12.11.0, PostgreSQL JDBC 42.7.14, Jackson 3.1.8, JUnit Jupiter 6.1.3, Mockito 5.24.0, Testcontainers 2.0.5, Tomcat 11.0.27. springdoc-openapi 3.2.x.
- **Java 21 LTS** (Temurin 21.0.13).
- **PostgreSQL 16** (16.16), поддержка до ноября 2028.
- Точные версии фиксируются в `pom.xml`; выпуски моложе 14 дней не берутся.

## Рассмотренные альтернативы

- **Boot 4.1.3** — более «обкатан», но поддержка закончится в середине работы над дипломом (07.2027); оставлен как резерв на случай проблем совместимости 4.2.
- **Java 25 LTS** — поддерживается Boot 4.2; переход возможен без изменений кода, но автор выбрал 21.
- **PostgreSQL 17/18** — доступны; 16 достаточно и поддерживается до 2028.

## Последствия

Boot 4 использует Jackson 3 (пакеты `tools.jackson.*`) и JUnit 6 — учесть в примерах из интернета, написанных под Boot 3. Flyway требует отдельный модуль `flyway-database-postgresql`.
